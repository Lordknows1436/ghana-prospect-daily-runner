# Greater Accra daily discovery

This small Node.js program runs around 08:17 UTC daily on a standard GitHub-hosted runner. It does not use an AI model, Codex, paid runners, paid search services or private social accounts. GitHub may delay scheduled runs.

Each day targets 30 unique Greater Accra businesses. Broad searches recur between rotating business categories and region tiles. The collector stops at 30 candidates, 30 small map searches or 16 minutes, whichever comes first; sparse listings, duplicates and source failures can produce fewer. At most two new companies are saved per search. Company identity and original map-object checks prevent duplicate entries. Published website links are checked; missing map links never establish website absence. Published map-tag business emails, phone numbers and explicitly labelled WhatsApp contacts retain their source and check date. Official website contacts are collected only after the website identity is verified. Missing contacts stay unverified; delivery and account activity are not tested. Linked social profiles, establishment evidence, rule-based website/software proposals and three-message drafts are prepared where sources permit. Source failures are recorded. No outreach is sent.

Only collector code and AES-256-GCM encrypted state/results are public. The encryption key is held in a repository Actions secret and the private app's runtime secrets. Private app notes, edited messages and owner contact lists are never read by the runner. Logs contain aggregate counts only.

The private app imports and validates encrypted results when opened. No visitor session or private app credential is stored here. The encrypted feed index retains 90 daily batches for offline catch-up. Pause or resume the schedule under Actions → this workflow → menu. Disable the workflow to stop collection.

A manual dispatch on an already completed 30-target GMT day does not repeat source queries. A one-time upgrade from the old ten-candidate target appends to the existing day within the same 30-candidate and 30-query limits, preserving its earlier records. One explicit retry is allowed when all sources were unavailable. Workflows never run on pull requests and third-party actions are pinned to commit SHAs. The built-in GitHub job token can write encrypted results only within this repository and expires after the run.
